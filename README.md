# cadcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [cadcraft](https://github.com/storytold/cadcraft), a AutoCAD-style CAD app by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/cadcraft/latest/`
- Specific version: `/cadcraft/v<version>/`
- Version list: `/cadcraft/versions.json`

Each version folder is the unmodified contents of upstream's `cadcraft-web-<version>.zip` release asset, including its license files. Upstream license: Apache-2.0. A scheduled workflow mirrors new releases.
